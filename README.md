## 🌐 Deployment with GitHub Pages

This portfolio can be hosted for free using GitHub Pages.

### Deployment Steps

1. Open the GitHub portfolio repository.
2. Upload the project files to the repository root.
3. Make sure `index.html` and the `assets/` directory are committed.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch.
7. Select the `/ (root)` folder.
8. Click **Save**.
9. Wait for the deployment to complete.
10. Open the published website URL displayed in GitHub Pages settings.

**Important:** GitHub Pages directly serves static files. You do not need to run `npm start` after deployment.

Never commit `.env` or other private configuration files to a public repository.
